# Chat by Barsik

Современный адаптивный мессенджер на Next.js с регистрацией, профилями, приватными диалогами и сообщениями в реальном времени. Демонстрационных аккаунтов, контактов и сообщений нет: каждый пользователь регистрируется самостоятельно.

## Запуск локально

1. Установите Node.js 20.9 или новее.
2. Создайте проект в [Supabase](https://supabase.com/dashboard).
3. В Supabase откройте **SQL Editor** и выполните содержимое `supabase/schema.sql`.
4. Скопируйте `.env.example` в `.env.local` и укажите URL и публичный anon key вашего проекта (Supabase → **Project Settings → API**):

   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anon-key
   ```

5. Установите зависимости и запустите приложение:

   ```bash
   npm install
   npm run dev
   ```

   Откройте http://localhost:3000. При первом открытии показывается регистрация; для уже зарегистрированных пользователей есть переключение на вход.

## Возможности

- Регистрация по email и паролю, подтверждение email, вход и выход.
- Персональный профиль с именем, описанием и цветом аватара.
- Поиск зарегистрированных пользователей по имени или нику.
- Приватные диалоги один на один, хранение сообщений в PostgreSQL и доставка новых сообщений в реальном времени.
- Row Level Security: доступ к переписке ограничен участниками диалога.
- Адаптивный интерфейс для телефона и компьютера.

Для проверки общения зарегистрируйте два собственных аккаунта в отдельных браузерах/окнах и найдите один аккаунт из другого по username или имени. В приложении нет демонстрационных аккаунтов или предзаполненных данных. Существующие реальные аккаунты в Supabase не удаляются.

> Supabase URL и anon key — публичные клиентские параметры; безопасность данных обеспечивают политики RLS. Никогда не размещайте `service_role` key в `NEXT_PUBLIC_*` или клиентском коде.
