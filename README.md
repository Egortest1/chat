# Салон — современный мессенджер

Next.js-приложение с регистрацией и входом через Supabase Auth, профилями в PostgreSQL, личными диалогами, сообщениями и обновлением сообщений в реальном времени.

## Запуск локально

1. Установите Node.js 20.9 или новее.
2. Создайте проект в [Supabase](https://supabase.com/dashboard).
3. В Supabase откройте **SQL Editor**, выполните содержимое `supabase/schema.sql`.
4. Скопируйте `.env.example` в `.env.local` и укажите URL и публичный anon key проекта (Supabase → **Project Settings → API**):

   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anon-key
   ```

5. Установите зависимости и запустите приложение:

   ```bash
   npm install
   npm run dev
   ```

   Откройте http://localhost:3000.

## Возможности

- Регистрация по email и паролю, вход и выход через Supabase Auth.
- Создание профиля при регистрации, поиск людей по имени/нику и редактирование имени, описания и цвета аватара.
- Приватные диалоги один на один, хранение сообщений в PostgreSQL и доставка новых сообщений в реальном времени.
- Row Level Security (RLS): читать сообщения могут только участники беседы; отправка разрешена только от имени текущего пользователя.
- Адаптивный интерфейс для мобильного и настольного экранов.

Для теста зарегистрируйте два пользователя в разных браузерах/окнах, затем найдите одного по username или имени.

> Supabase URL и anon key — публичные клиентские параметры; безопасность данных обеспечивают политики RLS. Никогда не размещайте `service_role` key в `NEXT_PUBLIC_*` или клиентском коде.
